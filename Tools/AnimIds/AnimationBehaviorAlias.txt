# Animation behavior aliases for the extended AnimationData rows (ground ids 506, 508, ... 1776).
#
# Why: every classifier in Unit_C.cpp (IsEmoteAnim, IsUpperBodyAnim, IsMeleeAttackAnim, IsSpellCastAnim, ...) looks the
# animation up in AnimationData.dbc and switches on its BehaviorID. An extended animation has to keep BehaviorID == its
# own id (AnimationData::FindIdByBehaviorAndTier finds a ground row, and its FLY twin, by that value), so it would fall
# outside every classifier set. This table says "classify this animation as that native one" without touching the DBC:
# the classifiers read the behavior through AnimClassBehavior() (AnimBehaviorAlias.h), which maps it here.
#
# Format, one animation per line (ids that are not listed keep their own behavior, i.e. stay plain whole-body animations):
#     <ground animation id>  <native animation it counts as>      # <this animation's name>  [<roles it gains>]  <confidence>
# The base is named like the enumerators in Types.h (EmoteTalk -> ANIM_EMOTE_TALK) and must be a native id (< 506); the
# generator checks both. The name after '#' is checked against AnimationNames.txt where that file knows the id. FLY twins
# need no line: their BehaviorID is the ground id, so they follow it. 'low' marks rows whose analog was a stand-in guess.
#
# Never alias onto a behavior that does more than classify: 1/6/131/132/466-472 (death), 37-40/187 (jump/airborne),
# 39/121/127/192/200/201/458-460/464 (they set animation-state bits). The generator refuses them.
#
